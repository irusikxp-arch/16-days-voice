# 16 днів: Голос, який чути 🕯️

Інтерактивна освітня гра (Phaser 3) проти насильства та булінгу — до кампанії
«16 днів проти насильства». Повністю українською.

**Особливість цієї версії:** уся графіка — єдиний мальований арт-пак у стилі
**Cozy Fantasy / Warm Semi-Realistic** (25 ілюстрацій: 8 фонів, 13 спрайтів персонажів,
4 об'єкти), інтегрований у код гри замість примітивних фігур.

## Що всередині

```
├── game/               # ГРА (Phaser 3, 1024×768, 8 рівнів + меню + фінал)
│   ├── index.html      #   весь код гри в одному файлі
│   ├── vendor/         #   локальний phaser.min.js → гра працює ОФЛАЙН
│   ├── assets/         #   backgrounds/ characters/ objects/ (прозорий фон)
│   ├── qa/             #   автоскриншоти headless-перевірки (Puppeteer)
│   └── README.md       #   деталі інтеграції ассетів у код
├── cozy-fantasy/       # АРТ-ПАК: джерела, game-assets, контакт-аркуші,
│   │                   # скрипти обробки (process_assets.py, make_sheets.py)
│   └── README.md       #   маніфест ассетів і стиль-гайд
└── README.md           # цей файл
```

## Швидкий старт

```bash
# варіант 1: просто відкрити у браузері (офлайн)
open game/index.html          # macOS / xdg-open на Linux

# варіант 2: через локальний сервер
python3 -m http.server 8080 --directory game
# → http://localhost:8080
```

Геймплей: клікай персонажів → слухай історії → збирай факти → рівень емпатії змінюється
від відповідей. 8 рівнів: булінг, кібербулінг, домашнє насильство, онлайн-переслідування,
домагання, фізичний тиск, звернення по допомогу, центр підтримки. У фіналі — контакти
допомоги в Україні (гарячі лінії).

## Регенерація / заміна ассетів

```bash
cd cozy-fantasy
python3 -m pip install pillow numpy
python3 process_assets.py   # прозорий фон (flood-fill + замкнені ділянки), кроп, розміри
python3 make_sheets.py      # контакт-аркуші sheet_*.png
cp -r game-assets/backgrounds game-assets/characters game-assets/objects ../game/assets/
```

Мапування ролей на спрайти — таблиця `CHAR_SPRITES` у `game/index.html`
(перевикористання спрайтів із тонуванням для епізодичних ролей; анонімні агресори —
темні силуети навмисно).

## Як викласти цей репозиторій на GitHub

Репозиторій уже ініціалізовано й закомічено локально. Залишилось зв'язати з GitHub:

1. На [github.com](https://github.com/new) створіть **порожній** репозиторій
   (без README/LICENSE/gitignore), напр. `16-days-voice`.
2. Прив'яжіть і завантажте (у терміналі цього середовища або на своєму ПК із цією текою):

   ```bash
   git remote add origin https://github.com/<ВАШ_НІК>/<НАЗВА>.git
   git branch -M main
   git push -u origin main
   ```

3. При першому push GitHub попросить автентифікацію: пароль **не приймається** —
   потрібен Personal Access Token (Settings → Developer settings → Tokens, scope `repo`)
   або SSH-ключ.

> Порада: створюйте **fine-grained token** лише з правом `Contents: Read and write`
> для цього одного репозиторія — і видаліть його після push.

Альтернативи без терміналу: GitHub Desktop (File → Add local repository → вказати цю теку)
або завантажити теку архівом і скористатися `github.com/new#import-your-code`.
