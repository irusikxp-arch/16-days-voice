# Cozy Fantasy — пакет ілюстрацій для гри

Усі 20 ассетів згенеровано в єдиному стилі **Cozy Fantasy / Warm Semi-Realistic Illustration**
і підготовлено для використання в грі: фони покраяно до 4:3, у персонажів та об'єктів
прибрано білий фон (справжня альфа, а не «біла плашка»), розміри приведено до технічних вимог.

## Структура

```
cozy-fantasy/
├── backgrounds/          # джерела фонів, 1024×1024 (square, без кропу)
├── characters/           # джерела персонажів на білому фоні, 1024×1024
├── objects/              # джерела об'єктів на білому фоні, 1024×1024
├── game-assets/          # ✅ ГОТОВО ДЛЯ ГРИ
│   ├── backgrounds/      # 1024×768 (4:3), центр-кроп з джерела
│   ├── characters/       # 200×400, прозорий фон (RGBA)
│   ├── objects/          # phone 64×64 · books 100×60 · bench 200×80 · notice 150×90 (RGBA)
│   └── cutouts/          # вирізані спрайти у максимальній якості, прозорий фон (RGBA)
├── sheet_all.png         # зведений контакт-аркуш усіх 20 ассетів
├── sheet_backgrounds.png / sheet_characters.png / sheet_objects.png
├── process_assets.py     # скрипт постобробки (кроп, alpha, розміри)
└── make_sheets.py        # скрипт контакт-аркушів
```

## Як це оброблялося (і як повторити)

1. Генерація: зображення 1024×1024 у джерелах (генератор не підтримує `--ar`, тому пропорції
   відтворено композицією + кропом).
2. `process_assets.py`:
   - фони — центр-кроп 4:3 → 1024×768;
   - спрайти — flood-fill від рамки зображення прибирає білий фон; **замкнені ділянки фону**
     (напр. між ногами) прибираються окремою перевіркою: компонент ≥ 2000 px, колір якого
     збігається з фоном (maxdist ≤ 6). Білі футболки/сторінки всередині силуету не чіпаються;
   - край силуету пом'якшено (gaussian 0.8 px), всередині фону альфа суворо 0;
   - кроп по bbox + вписування в цільовий розмір зі збереженням пропорцій.
3. `make_sheets.py` — контакт-аркуші для швидкого перегляду.

Повторний запуск (після будь-якої регенерації джерел):

```bash
python3 -m pip install --user pillow numpy     # або --target=<dir> + PYTHONPATH
cd cozy-fantasy
python3 process_assets.py
python3 make_sheets.py
```

## Інтеграція в гру

Готовий приклад використання пакета — у теці `../game/` (Phaser 3, гра «16 днів: Голос, який чути»):
фони рівнів, спрайти ролей через таблицю мапування, об'єкти-декорації, офлайн-Phaser у `vendor/`.
Деталі — у `../game/README.md`.

## Нотатки

- Консистентність пар (Аня/Марина) досягнута передачею першого зображення як референсу
  (аналог `--cref` у Midjourney) + дослівним повтором опису одягу.
- `notice.png` у джерелі намальовано як вертикальний стовп із дошкою; у коробці 150×90
  він вписаний із прозорими полями. Якщо потрібен суто горизонтальний щит — скажіть,
  перегенерую об'єкт окремо.
- Учитель вийшов чоловічої статі (у промпті стать не була вказана). Якщо потрібна жінка —
  перегенерую за хвилину.
