# Гра «16 днів: Голос, який чути» — версія з арт-паком Cozy Fantasy

Phaser 3 · 1024×768 · 8 рівнів + меню + фінал · прогрес у localStorage.
Уся графіка — згенеровані ілюстрації замість кольорових прямокутників.

## Структура

```
game/
├── index.html          # весь код гри (один файл, як в оригіналі)
├── vendor/phaser.min.js# локальний Phaser 3.70 (офлайн-режим; CDN — лише fallback)
├── assets/
│   ├── backgrounds/    # 8 фонів 1024×768 (4:3)
│   ├── characters/     # 13 спрайтів 200×400, прозорий фон
│   └── objects/        # 4 об'єкти: phone 64×64, books 100×60, bench 200×80, notice 150×90
└── qa/                 # автоскриншоти headless-перевірки (menu, scene1, scene4, scene8…)
```

## Як запустити

- **Просто відкрити `index.html` у браузері** — працює офлайн, бо Phaser лежить у `vendor/`.
- Або через сервер: `python3 -m http.server 8080 --directory game` → http://localhost:8080

## Що змінено щодо оригінального коду

1. **BootScene.preload** завантажує 25 ассетів і керує прогрес-баром (`load.on('progress')`);
   екран завантаження ховається по `load.on('complete')`. Раніше бар не оновлювався.
2. **Меню**: мальований фон `school_yard` + затемнення; сітка картка посунута, щоб не
   перекривати підзаголовок і статистику; обабіч — спрайти героя та Ані.
3. **Рівні**: фон рівня (`LEVELS[i].bg`), декорації-об'єкти (`LEVELS[i].decor`), затемнені
   смуги під HUD для читабельності.
4. **Персонажі**: замість прямокутників — спрайти з тінню, табличкою імені, ховер-твіном
   і бейджем ✅ після зібраного факту. Глибина сортується за `y` ніг.
5. **Мапування ролей** — таблиця `CHAR_SPRITES` (номер рівня → роль → спрайт):
   `{ s, tint, flip }` дозволяє перевикористати спрайт з тонуванням/дзеркаленням.
   Анонімні агресори навмисно темні силуети (`tint: 0x3a3a4d` тощо).
   Якщо спрайт не знайдено — спрацьовує старий фолбек із прямокутників.
6. **HUD**: «Факти», «Емпатія», «Меню» вирівняні правими краями — більше не перекриваються.
7. **Scene8**: окрема лінія підлоги `groundY: 745` (персонажі перед столом, не на ньому).
8. **Фінал**: фон `support_center` + герої обабіч.
9. Додано `favicon` (data-URI) — прибрито 404 у консолі.

## Як поміняти спрайт ролі

```js
const CHAR_SPRITES = {
  5: { iryna: 'iryna',                                   // власний спрайт
       stranger: { s: 'oleg', tint: 0x54403a },          // перевикористання + тон
       guard: { s: 'teacher', tint: 0x9fb4ff } },
  ...
};
```
Ключі спрайтів: `anya, anya_happy, oleg, marina, marina_brave, teacher, psychologist,
player, maxym, olya, katya, iryna, dima`.

## Як оновити ассети після регенерації

Джерела та скрипти обробки — у теці `../cozy-fantasy/`:

```bash
cd ../cozy-fantasy
python3 -m pip install pillow numpy
python3 process_assets.py     # прозорий фон, кроп, цільові розміри -> game-assets/
python3 make_sheets.py        # контакт-аркуші
cp -r game-assets/backgrounds game-assets/characters game-assets/objects ../game/assets/
```

## Перевірка якості

`qa/` містить скриншоти headless-Chrome (Puppeteer): меню, меню з прогресом, рівні 1, 4, 8,
діалоги та збір факту. Останній прогін: **0 помилок консолі, 0 невдалих запитів**.
(У скриншотах emoji можуть бути «квадратиками» — у тестовому Chrome немає emoji-шрифту;
у звичайному браузері вони відображаються.)
